- experiments/utils/run_core.sh:26-27,31-35,226-228 — `run_experiment()` now takes a 4th `client_eth0_mac` parameter and forwards it to `clientnic.sh` via the `CLIENT_MAC` env var, alongside the existing `SKIP_BUILD`/`PORT_COUNT` pass-through.
- experiments/dpdk/run_experiment.sh:114-126,134,157 — resolves `CLIENT_ETH0_MAC` (DeviceIndex=0 of `smartnics-client`) via the EC2 API alongside the other peer MACs, passes it as the new 4th arg to `run_experiment`, and adds it to the ClientNIC smoke-test's direct binary invocation (`--client-mac=$CLIENT_ETH0_MAC`) so the smoke test doesn't fail on the same missing-required-flag error.
